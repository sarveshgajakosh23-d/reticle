From photograph to clinical judgment, in six visible steps.

Reticle doesn't hide the reasoning behind a single confidence number. Each screening moves through the same visible pipeline, so the person reading the result can see exactly how the AI got there.

01Capture

A retinal photograph is taken with a standard or handheld fundus camera.

02Vision

The model maps retinal structures — vessels, disc, macula — before looking for disease.

03Understand

Regions that deviate from healthy retinal patterns are located and scored.

04Explain

Each detected region is turned into a plain-language finding, not just a number.

05Act

Findings are placed on a risk scale with a clear, specific next step.

AI-assisted means a person always confirms.

Reticle is designed to support a screening decision, not to make one on its own.

Human-in-the-loop

Every flagged case routes to a clinician for review before any action is taken.

Explainable by default

Findings are shown with the region and reasoning behind them — never a bare percentage.

Image quality checks

Poor-quality captures are flagged before analysis, not silently scored anyway.

Privacy-conscious

Case data stays scoped to the screening workflow it was collected for.

Clinical confirmation required

Every report states plainly that AI screening is not a diagnosis.

Built for real conditions

Designed to hold up on the camera equipment and image quality found in the field, not just a lab dataset.

About this project

Reticle is a prototype built for the Smart India Hackathon, exploring how AI-assisted retinal screening can be made accessible and explainable for community health settings. The result you see in the demo below runs entirely in this browser on sample and mock data — a production version would connect the same interface to a trained model and a real screening pipeline.

Reticle provides AI-assisted screening support. It does not diagnose disease and does not replace evaluation by a qualified clinician.
